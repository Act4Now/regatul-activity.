REGATUL ACTIVITY — PWA

500 provocări: 200 desen, 200 mimă, 100 întrebări.

PUBLICARE GRATUITĂ PRIN GITHUB PAGES:
1. Creează un repository public nou în GitHub.
2. Încarcă toate fișierele din arhivă în rădăcina repository-ului.
3. În Settings > Pages, la Build and deployment, selectează Deploy from a branch.
4. Alege branch-ul main și folderul /(root), apoi Save.
5. După publicare, deschide URL-ul HTTPS primit în Chrome pe Android.
6. În Chrome apasă ⋮ > Install app (sau Add to Home screen, în funcție de dispozitiv).

PWA necesită HTTPS și manifest valid. Nu este un APK tradițional. Progresul este salvat local pe dispozitiv prin localStorage.
